
# Mauli Group Website

A corporate construction company website and DevOps portfolio project.

## Project Structure

- `frontend/` — React and Vite frontend
- `backend/` — Node.js and Express API
- `database/` — Database schema
- `docker/` — Docker-related configuration
- `terraform/` — Infrastructure as Code configuration

## Development

See the frontend and backend folders for their respective setup instructions.

## Security

Keep environment files, passwords, tokens, and other secrets out of GitHub.
